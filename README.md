# keion-attendance-system
120名規模　軽音学部向け自動出欠管理システム

LINEだけで出欠を記録し保管できるBotです。Google Apps Script単体（外部サーバー不要）で動作し、自由な文章での連絡もAIが解析して記録します。

概要:
人の手による出欠管理作業が膨大になっていたので、何とか削減したいというモチベーションから作りました。単純な「出席/欠席」のボタン操作だけでなく、「明日の集会、体調不良で休みます」のような自然な文章を送っても、AIが日付・状況・理由を読み取って記録してくれるのが特徴です。

できること:
・出席登録：合言葉（当日のパスワード）を送ると出席として記録
・欠席・遅刻連絡：日付・理由付きで記録（定型フォーマット／自由文どちらも対応）
・連絡の取消：記録済みの出欠を取り消し
・予定表確認：登録されているイベントスケジュールをLINE上で確認
・自由文解析：「来週の練習、遅れて行きます」のような曖昧な表現もAIが解釈して記録

使用技術:
・Google Apps Script（バックエンド／Webhookエンドポイント）
・LINE Messaging API（ユーザーとのやり取り）
・Gemini API（gemini-2.5-flash、自由文からの情報抽出）
・Google スプレッドシート（データベース代わりに使用）

設計のポイント:
・入力規制ではなく、入力補正　ルールを厳格にするとエラーで混乱させてしまうのである程度自由文でもOKな設計にしました。

・正規表現＋AIのハイブリッド構成　「〇月〇日 欠席 体調不良」のような定型フォーマットは正規表現だけで即座に処理し、それ以外の自由な文章のときだけGemini APIを呼び出す設計にしています。これにより、多くのケースでAI呼び出しのコストとレイテンシを避けられます。定型入力に慣れたユーザーは高速に、慣れていないユーザーは自然文で、という2通りの使い方を両立させています。

・排他制御　複数人がほぼ同時にメッセージを送ってきても、スプレッドシートへの書き込みが競合しないようLockServiceで排他制御を行っています。GAS＋スプレッドシートという構成は同時アクセスに弱いため、実運用では必須の対策です。
